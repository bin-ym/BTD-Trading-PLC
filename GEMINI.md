# Project Guidelines & Assistant Rules

## Session Completion Rule: Grouped Commit Messages
At the end of every task or session, always provide a clean git commit message formatted with logical grouping:
- Use Conventional Commits (`feat`, `fix`, `refactor`, `docs`, `chore`, etc.).
- Group related changes together by scope/area (e.g., Gallery & UI, Translations & i18n, Docs).
- Provide a clear one-line subject line followed by bullet points grouped by category.
